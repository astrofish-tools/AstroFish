# Changelog

## 1.0.0 — 2026-09-17

- First formal AstroFish release.
- Added normal and enhanced Star View live preview.
- Added normal and Star View clean-preview modes.
- Added shutter, electronic aperture, ISO, shot count, delay, and interval controls.
- Added manual-focus magnification and movable focus area.
- Added live luminance histogram with Sony native analysis and fallback handling.
- Added timed BULB and long-exposure interval sequences.
- Added card playback, 1×/2×/4× zoom, and captured-photo histogram.
- Added capture-parameter restoration around Star View.
- Added the flying-fish-and-star launcher icon.
- Added bilingual user guide and one-page quick-reference card.
